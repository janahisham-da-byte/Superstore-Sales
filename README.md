# Superstore Sales Dataset Analysis

## Project Description
This project focuses on analyzing store sales data using Power BI to evaluate overall business performance. It aims to clean the transactional data and create an interactive dashboard that shows how different product categories and geographical regions impact sales and profitability, helping managers make better data-driven decisions.
